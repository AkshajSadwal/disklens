DiskLens phase 1 reliability update

Changes:
- Scan roots are normalized and duplicate roots removed.
- Nested/overlapping roots are rejected, including case-insensitive Windows path comparisons.
- Symlink scan roots are rejected before launching the collector.
- New scans are rejected when they overlap an active job.
- Multi-root completion/failure/cancellation outcomes are retained briefly so queued roots cannot inherit stale completion state from an older scan.
- API shutdown now sends a graceful cancel, waits for collector exit, and cleans unfinished staged rows before SQLite is closed.
- Added tests for scan-path safety, Windows path comparison, multi-root outcomes, and cancellation during upload.
- Added roadmap and coding-agent prompt with bounded token, cost, and test use requirements.

Validation:
- `node --test tests/*.test.mjs`: 19 passed, 0 failed, 0 skipped.
- No full-drive scan, large stress test, hosted AI call, or paid token was used.
- Native Windows/macOS/Linux smoke tests remain manual; see TEST_REPORT.md.
