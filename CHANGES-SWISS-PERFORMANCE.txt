DiskLens — Minimal / Swiss Style and Performance Update

UI changes
- Applied a restrained Swiss-style visual system: neutral surfaces, cobalt accent, strong typography hierarchy, consistent spacing, crisp borders, and fewer decorative effects.
- Refined the existing Home, Storage Explorer, Programs & Cleanup, AI Storage Advisor, and Settings layouts without removing the current navigation or feature flows.
- Improved small-label readability, empty states, controls, and responsive behavior.

Performance changes
- The recursive Storage Explorer sunburst now loads only when the Storage section is opened.
- Sunburst folder requests are concurrency-limited and aborted when the user navigates away or changes the selected path.
- Home no longer performs per-drive folder-size aggregation during initial load; it is deferred until the Folders filter is selected.
- Folder listing aggregates descendants inside SQLite using indexed path ranges instead of returning all descendant rows to Node for aggregation.
- Explorer path scopes and folder-size queries use indexable path ranges instead of substr-based full-index filtering.
- AI storage folder aggregation and item detail folder sizes use indexed path ranges; root entries are excluded from their own child listings.
- Reused memoized Sunburst layout and Home dashboard derived data, and cancel stale overview/folder requests.
